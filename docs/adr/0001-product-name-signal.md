# ADR 0001: Use Signal as the product name

Status: accepted — 2026-07-18

## Context

The supplied FRD uses “Persistent Operator” as a working name. The repository and user request name the product Signal.

## Decision

Use Signal in code, package names, UI, deep links, and deployment identifiers. Preserve “Persistent Operator” only in the source requirements. This is a naming decision; all FRD behavior remains authoritative.

## Consequences

Legal and app-store naming clearance remains a pre-launch business gate because an established messaging product also uses “Signal.”
