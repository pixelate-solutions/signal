# Runbook: browser compromise

1. Terminate the session/container and revoke its capability and credential leases.
2. Quarantine downloads, browser state, screenshots, and network metadata.
3. Disable affected domain/skill version and pause related tasks.
4. Revoke provider session/token when theft is plausible; notify security and the user with privacy-safe detail.
5. Preserve encrypted evidence, rotate worker identity, patch, regression-test injection/egress fixtures, and canary before re-enable.
